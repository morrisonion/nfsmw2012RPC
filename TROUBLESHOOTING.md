## Troubleshooting

| error | reason | solution |
| :--- | :--- | :--- |
| **`Game exe not found`** | the game exe was not found | check the filename of your Game exe file(should be named `NSF13_Game.exe`) and/or the directory where you put the discord rpc exe |
| **`Discord App not running`** | your discord app does not run in the backround | start your discord app |
| **`Could not start game executable`** | not specified(dynamic) | make sure the file is not blocked or damaged |
