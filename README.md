# nfsmw2012RPC
Discord RPC for Need for speed: most wanted (2012)

# Installation
### 1. Open your Game directory in explorer
- Steam: `C:\Program Files (x86)\Steam\steamapps\common\Need for Speed Most Wanted`
- EA App: `C:\Program Files\EA Games\Need for Speed Most Wanted`
- If you installed your game at a custom path then go to the game directory
### 2. In your Game directory rename `NFS13.exe` to `NFS13_Game.exe`
### 3. Download `NSF13.exe` from the [latest release](https://github.com/morrisonion/nfsmw2012RPC/releases/latest) and put it into your game directory
### 4. Now launch `NSF13.exe` with an open discord client
